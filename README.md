# Siri Voice Deck

A lightweight, automated voice deck application for flight simulation and virtual ATC networks.

## Features

- **Automated Updates**: `Siri.exe` automatically syncs the latest files directly from the official repository on startup.
- **Clean Installation**: All application source code and runtime assets are safely stored in `%LOCALAPPDATA%\SiriVoiceDeck`, keeping your user directory clean.
- **Zero Configuration**: Simply double-click `Siri.exe` to check for updates and launch the application automatically.

## Requirements

- **Windows 10 / 11**
- **Python 3.x** installed (with the `py` launcher enabled)
- **Git for Windows** installed (required for auto-updates)

## Quick Start

1. Extract the downloaded zip file to any folder of your choice.
2. Run **`Siri.exe`**.
3. On first launch, the application will automatically clone the necessary files and dependencies into your local AppData folder and start `Siri Voice Deck`.
